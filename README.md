# content-studio-pages

Pagina di presentazione, norme sulla privacy e termini di servizio di
**Content Studio**, un progetto personale che gira in locale.

Questo repository contiene soltanto pagine statiche, pubblicate con GitHub
Pages perché Google e TikTok richiedono indirizzi pubblici per la home page,
le norme sulla privacy e i termini di un'applicazione che usa le loro API. Il
codice dell'applicazione non sta qui.
