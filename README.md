# content-studio-pages

Pagina di presentazione e norme sulla privacy di **Content Studio**, un progetto
personale che gira in locale.

Questo repository contiene soltanto due pagine statiche, pubblicate con GitHub
Pages perché Google richiede un indirizzo pubblico per la home page e per le
norme sulla privacy di un'applicazione che usa le sue API. Il codice
dell'applicazione non sta qui.

- [Home](https://1997giaquinto.github.io/content-studio-pages/)
- [Norme sulla privacy](https://1997giaquinto.github.io/content-studio-pages/privacy.html)
